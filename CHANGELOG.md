# Changelog

## 0.2.0

Current-version baseline documented on 2026-09-29; this is not a new release.

- Manually pass compositor shortcuts through to VMs, VDIs, and remote desktop clients.
- Hide and restore the Omarchy bar with a vendor-neutral guard while preserving an already-hidden bar.
- Restore toggle state after shell restarts and provide an emergency shortcut to return to local input.
- Include a separate read-only Horizon status detector.
